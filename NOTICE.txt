1. Ruby's RBS type signatures
-------------------------------------------------------------------------------

The `core/` and `stdlib/` directories of the `rbs` gem, version 4.1.3, are
included verbatim and unmodified and are compiled into the `ya-lsp` binary, so
that Ruby's built-in classes can be answered for on a machine with no Ruby
installed.


2. The rbs C parser
-------------------------------------------------------------------------------

The `ruby-rbs` and `ruby-rbs-sys` crates compile the `rbs` gem's C parser into
the binary. They are listed in THIRD-PARTY-NOTICES.txt along with every other
crate ya-lsp links, but that file is generated by `cargo about` from the
dependency graph and neither crate ships a licence file for it to harvest — so
it reproduces the SPDX template, whose copyright line is the unfilled
placeholder "Copyright (c) <year> <owner>". The notice below is theirs as well.
