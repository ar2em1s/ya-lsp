# Licences and notices

## The three files

| File | Holds | How it is kept correct |
|---|---|---|
| `LICENSE.txt` | MIT, and nothing else | A test asserts no `---` and no `Soutaro`, and CI checks the copy in the VSIX |
| `NOTICE.txt` | The rbs notice: the vendored signatures and the `ruby-rbs` / `ruby-rbs-sys` crates | A test checks it against `vendor/rbs/BSDL` + `COPYING` verbatim; another pins the rbs version |
| `THIRD-PARTY-NOTICES.txt` | About 100 crates linked into the binary | Generated by `cargo about` and committed; `make notices-check` diffs it byte for byte |

## Must

1. **Keep `LICENSE.txt` pure MIT.** Anything appended stops `cargo about` and GitHub from
   recognising it as MIT.
2. **Never delete `NOTICE.txt`.** It is the only place that names the rbs copyright holder:
   `cargo about` never sees the signature files, and the rbs crates publish no licence file. After
   a `vendor/rbs` bump, rebuild it from the files instead of editing the text by hand.
3. **Run `make notices` after any dependency change.** Both `ci.yml` and `release.yml` run
   `make notices-check`. The release run is needed because a tag push does not trigger `ci.yml`.
4. **Treat adding to `about.toml`'s `accepted` list as a decision.** An unlisted licence fails
   generation on purpose. The order matters, because the first match wins, which is why `MIT`
   comes before `Apache-2.0`.
5. **Pin the `cargo-about` version only in the `Makefile`.** `make setup-notices` installs it.

## Ship notices per artifact, not per repository

- **The binary** carries all three files: `ya-lsp --licenses` (`src/licenses.rs`) prints them
  through `include_str!`.
- **The VSIX** gets them through `vscode:prepublish` → `stage-shared`, which copies the root files
  with `node -e` because some release runners are Windows.
  - A missing root file fails packaging.
  - `editors/vscode/.gitignore` lists the staged copies, so nobody edits one by mistake.
- **The `.tar.gz` and `.zip` archives** ship the files next to the binary. CI checks each one on
  the platform that built it.
- **`CHANGELOG.md` rides along** with the VSIX for the same reason. `vsce` lowercases it to
  `changelog.md`, which is what the Marketplace reads.

## The one argued licence: `CC0-1.0`, for `notify`

- **Why it is accepted:** it is a public-domain dedication with no conditions. rust-analyzer and
  watchexec ship the same crate. The alternative was no file watching for clients that cannot
  register a watcher.
- **Its weakness:** §4(a) does not waive patent rights. That is why OSI never approved it and
  Fedora stopped accepting it for code.
- `about.toml` carries the same argument next to the entry.
